# Video Walkthrough Guide
## Suggested structure
1. Title and manual-handoff problem (15s)
2. Architecture and local fallback (25s)
3. Requirement and discovery agents (35s)
4. BRD gate, backlog, sprint and code-plan gate (50s)
5. Generated code, review, sanity and QA handoff (40s)
6. Lineage graph, business value and close (25s)

## Screens and narration
Show dashboard status cards, workflow stepper, BRD confidence sections, GWT criteria, both gold approval cards, generated layers, review findings, QA checklist, and the final graph. Narrate stable IDs at every transition and mention that Ollama is optional rather than required.

## Rubric alignment
- **Innovation:** coordinated role-specific agents plus semantic lineage.
- **Completeness:** requirement-to-release runnable workflow.
- **Quality:** DTO validation, layer boundaries, negative tests, honest findings.
- **Usability:** single dashboard with visible state and artifacts.
- **Feasibility:** local JSON and deterministic fallback keep setup reliable.
- **Business impact:** less rework, stronger governance, retained knowledge.

Record at 1080p with browser zoom near 100%; avoid embedding the video in the ZIP and keep the separately submitted file under 50 MB.
