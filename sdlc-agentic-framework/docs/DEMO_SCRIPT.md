# Three-Minute Demo Script
**0:00–0:25 — Problem.** “Feature delivery loses time and intent across BA, product, engineering, QA and release handoffs. Artifacts are recreated and lineage is rarely provable.”

**0:25–0:45 — Solution.** “This local-first framework coordinates twelve specialized agents. It needs no paid API, remains predictable offline, and makes human approval a first-class workflow state.”

**0:45–1:35 — Live flow.** Paste the leave feature and click **Run SDLC Agents**. Point out completed discovery stages, normalized IDs, retrieved context and confidence-scored BRD. Approve BRD. Open backlog and show Given/When/Then criteria, estimates, dependencies, sprint and code plans. Explain that code cannot run before the second approval.

**1:35–2:25 — Delivery.** Approve the code plan. Open generated DTO/service/repository/UI/test stubs, then review findings, sanity result, and the QA release checklist. Mention deterministic negative cases: duplicate dates, insufficient balance, and missing fields.

**2:25–2:45 — Innovation.** Load lineage and follow REQ-001 → BRD → epic → story → AC → code → test → review → sanity → QA → release. This is semantic evidence, not a folder listing.

**2:45–3:00 — Impact and close.** “Teams gain faster handoffs, consistent quality, reusable knowledge and auditable human control. This PoC proves a practical path from a sentence to release-ready evidence—in one local application.”
